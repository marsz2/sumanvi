# Sumanvi / J S K Enterprises B2B Marketplace

Simple static frontend + Supabase backend.

Files:
- index.html — marketplace, login and admin dashboard UI
- blog.html — public blog page
- app.js — Supabase connection, authentication, CRUD and image uploads
- vercel.json — makes `/blog` work with `blog.html`

Never put a Supabase service-role key in app.js. Use only the publishable key.
